# Evidências do Gemini Notebook

Esta pasta é destinada aos prints do chat com as citações abertas.

Arquivos recomendados:

- `01-fontes-e-estudio.png` — visão geral do notebook com as 15 fontes e o Estúdio;
- `02-dor-de-cabeca-citacao.png` — resposta sobre dor de cabeça com uma fonte aberta;
- `03-cuidados-cartilha.png` — síntese de cuidados e recomendações com citação da cartilha aberta;

Os prints servem como evidência de que as respostas do notebook são fundamentadas nas fontes selecionadas e permitem rastrear o trecho utilizado.
